# Changelog

## 1.1.0 — First public release

- Dark desktop interface with gold accents, a custom window frame, and subtle input borders.
- Script editing with exact message previews and visible pauses.
- Whole-word wrapping to Dark Ages' 59-character chat limit.
- Start, pause, resume, and stop controls with optional global shortcuts.
- Adjustable message and paragraph delays, plus explicit script waits.
- Draft persistence and plain-text import/export.
- Window identity checks, clipboard restoration, and interruption recovery.
- Troubleshooting logs and configurable input timings in Settings.
- Compact window layout and support for display scaling.
- Design credit to Aosda and acknowledgments for ewrogers' SleepHunter work.
